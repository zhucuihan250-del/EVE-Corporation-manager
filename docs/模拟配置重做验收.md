# 模拟配置重做验收

日期：2026-10-03。本文区分已验证的行为、已实现但仍需验收的界面，以及尚未完成的生产证据。不得将本次重做描述为已经与 EVE 客户端逐项一致。

当前完成状态：计算核心、兼容 API、配置保存/权限、本地工作台与两种舰船的真实 3D 渲染/旋转/缩放/复位已通过；最终根构建通过；重做版本已发布并完成线上 HTTP/资源/迁移检查；真实 ESI 授权及游戏内数值对照尚未验证。

## 交付范围

- 游戏式装配工作台：独立的高、中、低、改装件、子系统与建筑服务槽；每个槽位保存独立装备及状态，不再仅用同型装备总数量模拟。
- 装备可切换离线、在线、激活、过热；计算结果同时返回请求状态、实际状态和可达到的最高状态。
- 选择兼容弹药或脚本，区分无人机携带数量与出战数量，支持货舱、植入体、增效剂及适用舰船模式。
- 技能选择为全 V、无技能或本人绑定角色；角色计算读取 ESI 的实际生效等级，而非仅使用已训练等级。
- 展示 CPU、能量栅格、校准值、槽位、炮台/发射器、抗性、有效生命、伤害、电容、航行、锁定、无人机、修复与货舱数据；超配与缺少技能通过限制报告反馈，不将结构有效的超配方案直接丢弃。
- 支持中英文 EFT 导入、导出，个人及军团配置保存、读取、编辑、删除，以及基于版本号的冲突保护。
- 真实舰船 3D 预览使用 CCP 公共模型资源及 MIT 渲染器；模型读取、旋转、缩放、WebGL 兼容和失败恢复须另行浏览器验收，不以静态图片或占位图代替验收。

此范围不包括向游戏创建配装、装船、买卖物品、提交合同或发送任何游戏内操作。

## 计算与数据版本

计算库固定为 MIT 的 `@eveshipfit/dogma-engine@13.1.0`，搭配 `@eveshipfit/sde@8.3561556.0`。网站搜索目录由同一份官方 JSONL SDE 构建，禁止混用原来的 3444265 数据。

目录含 27,151 个类型，涵盖已发布舰船/建筑、装备、弹药、无人机、铁骑舰载机、子系统、植入体、增效剂、技能及货舱物品；另保留适用的战术模式类型。模型静态元数据亦来自 3561556；可用的 CCP 客户端资源索引在请求时独立解析，因此模型资源版本不等于计算 SDE 版本。

旧客户端仍收到 `precision: "approximate"`，新字段 `calculationPrecision: "dogma"` 标识所用计算引擎。这是兼容措施，既不表示仍沿用原始属性简单相加，也不保证数值已与游戏客户端逐项对照。

### 精度边界

- 本次已验证技能、舰船、装备、弹药、状态与叠加惩罚能够实际改变结果，但尚无逐项 EVE 客户端或独立配装工具对照验收；不可声称“100% 游戏一致”。
- DPS 和齐射属于所选条件下的理论值，不等于实战命中或实际伤害。距离、角速度、目标体积、导弹应用、目标抗性及交战情况会改变实际效果。
- 持续 DPS 与电容计算采用引擎的理论装满弹仓/循环假设。`chargeQuantity` 保留为兼容存储字段，不输入本版计算引擎；界面不应提供“数量已经影响计算”的暗示。
- 当前未提供突变装备属性、投射效果、指挥脉冲、任意战场环境、增效剂负面效果选择及完整铁骑技能按钮状态编辑；这些不能因引擎底层支持而视为网站已经交付。
- 反应式装甲采用不自适应环境设置；不得将其结果当作任意战斗条件下的最终抗性。

## EFT 使用约束

EFT 不能完整保存角色技能、来袭伤害比例、装备激活、过热及其他运行状态。导入后须重新检查状态与无人机出战数量；导出后再导入不应宣称保留了完整模拟快照。

已验证没有末尾换行的文本、中英文物品名、空槽、相同装备的独立槽位、装填弹药、离线标记与货舱内容。配置名称可含军团常用的 `[PVP]` 标签，但禁止换行及空字符。

## 安全与兼容验收

- 新接口沿用登录、军团上下文及舰队模块权限；不绕过现有权限模型。
- 个人配装仅本人可读取和修改，管理员亦不能读取他人的个人配装；军团配置读写按现有角色及 `fleet.manage` 权限执行。
- 角色技能只能读取本人有效、同军团绑定角色，不接受客户端提交的任意角色技能映射；不会向响应泄露刷新令牌、访问令牌、SQL 或堆栈。
- 0032 迁移为新增表/索引，测试证明重复执行安全，且不预置或删除配置。实际生产迁移结果仍须发布时补证。
- 模拟输入进入 WASM 前执行类型、数值、物品存在性和总量检查；计算隔离到工作线程，队列和超时有界。资源接口只读取指定 CCP 公共资源域及允许的游戏渲染路径，不作为任意 URL 代理。
- 旧 `/fitting/simulate` 字段与鉴别值保留，新工作台、保存、角色技能与模型元数据接口为增量新增。

3D 接口还验证非法 URI 编码安全返回 400；`Sec-Fetch-Site: cross-site` 在鉴权后返回 403，避免外站利用登录 Cookie 热链资源消耗限额，未登录仍优先返回 401。额度锁改用 `FOR NO KEY UPDATE`，避免与新配装外键所需的 KEY SHARE 锁相冲突；单 fixture 额度恢复测试已通过，但隔离 PGlite 不能证明真实 PostgreSQL 多会话锁竞争表现。

兼容 API 验证覆盖旧请求中的 `shipId` 和装备数量列表、原有资源/槽位/防御/移动/电容/输出字段，以及保留的 `precision` 鉴别值。新工作台结果增加规范化配置、真实状态、限制报告和详细统计；JSON 序列化后通过生成 Zod 响应契约验证，不把原始 Map 直接交给客户端。精确编号目录一次最多查询 100 个编号，返回缺失编号，避免导入配置中的物品名因搜索分页丢失。
