# EVE 预警桥接器使用指南

## 用途

预警桥接器读取本机 EVE 客户端已经生成的指定聊天频道日志，并只把包含军团监控星系名称的新消息发送到军团网站。它不会控制游戏客户端、模拟按键、读取缓存或监听网络。

## 准备

1. 电脑需要安装 Node.js 20 或更高版本。
2. EVE 客户端需要能够在“文稿/Documents”目录保存游戏日志。
3. 网站内至少已经添加一个监控星系。
4. 由 FC、管理员或拥有舰队管理权限的成员进入“星系监控管理”。

## 配对

1. 在“星系监控管理”下载 `eve-intel-bridge.mjs`。
2. 点击“生成配对码”，配对码在 10 分钟内有效并且只能使用一次。
3. 打开终端或 PowerShell，进入下载目录。
4. 执行：

   ```text
   node eve-intel-bridge.mjs
   ```

5. 按提示填写网站地址、配对码、设备名称、聊天日志目录和预警频道名称。
6. 回到网站，在“已配对设备”确认设备显示在线。

## 频道白名单

每台设备必须设置允许读取的频道名称。名称必须与 EVE 聊天日志头部记录的频道名称一致，每行一个。白名单为空时，桥接器不会上传任何消息。

推荐情报格式：

```text
!intel 1DQ1-A +12 敌对 重拦+战列 向T5ZI-S ttl=20
```

自然语言也可以识别，但消息中必须出现已经配置的完整星系名称。

## 隐私与审计

- 既有聊天历史不会上传。
- 普通聊天不会上传。
- 只上传白名单频道中包含监控星系名称的新消息。
- 临时断网时，待发送情报会保存在本机受限目录，恢复连接后自动重试。
- 网站记录游戏内报告角色和负责转发的桥接设备。
- 未绑定本站的报告角色会标记为“待确认”。

## 撤销和重新配对

管理员可以在网站撤销桥接器令牌。设备本地如需清除配对信息，执行：

```text
node eve-intel-bridge.mjs --reset
```

清除后需要重新生成一次性配对码。
